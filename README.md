## Swarm Build Assembly

The website factory can assemble generated code directly from agent JSON payloads without manually copying code blocks.

1. Save the final `frontend-agent` JSON to `.swarm/frontend-agent.json`
2. Save the final `backend-forms-agent` JSON to `.swarm/backend-forms-agent.json`
3. Run `npm run write-build`

This writes every entry from each payload's `generated_files` object into the matching local file path. The script creates missing directories automatically and keeps all writes inside the project root.

To run assembly and the production build together before the deployment step, use:

```bash
npm run prepare-deploy
```
